# ペット記録アプリ

体重・写真・メモを、記録した日時つきで残すPWA(スマホのホーム画面に追加して使う)。

- 構成: 素のHTML/CSS/JS(`docs/`がそのまま公開物)。バックエンドなし。
- 保存先: 端末内のIndexedDBのみ(クラウド同期なし)。写真は長辺1280pxに縮小して保存。
- 日時: 記録時に現在日時を自動入力(変更可)。写真は「ファイルの日時を使う」も選べる。
- 機能: 複数ペット登録、体重グラフ(1か月/3か月/1年/全期間)、前回比、写真グリッド、メモ、JSONバックアップ書き出し/読み込み。
- アイコン: `icon-original.png`(クロコ確認フォルダの素材)から、白い角を塗って全面正方形にした`icon-square.png`を作り、`docs/icons/`に各サイズを出力。
- 更新時: `docs/service-worker.js`のCACHE_NAMEは、ネットワーク優先方式のため基本そのままでOK。
## 3Dモデル
- チンチラ本体・衣装(くまのきぐるみ/着物/忍者/スーツ/ウェディング)はライフロードの素材をコピー。
- うさぎ・かえるの着ぐるみは2026-10-05に新規作成: クロコ確認フォルダの2Dイラスト(IMG_5982/IMG_5962)→Meshy API Image-to-3D(meshy-5・1枚画像・リメッシュ15000・PBRなし、各15クレジット)→Blenderでテクスチャ1024・Draco・JPEG。入力画像は3d-source/。グレー版のみ(白パイド版は未作成)。
- 衣装の解放日数はdocs/app.jsのCOSTUMES。
